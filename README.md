# Botclub Labs Web

The student website: sign up, choose a plan, pay, learn. Express + MongoDB, no build step.
Lessons are the same NCERT simulators as the apps, served only to signed-in students whose plan allows them.

## What is in here

- **The student website**: sign up, choose a plan, pay with Razorpay, learn (lessons only open for students whose plan allows them).
- **Admin** (`/admin`): sales, students, payments, plans, and **App usage**: how the Windows / Android / Linux apps are used in schools (hours, schools with combined curriculum progress, screens, chapters, CSV download), plus how students use the website.
- **App reporting API** (`/api/v1`): the apps register and send usage here. This replaces the separate analytics backend and dashboard.

## Run it on your computer (no database or payment account needed)

```bash
npm install
npm run demo        # http://localhost:8095  (in-memory database, FAKE payments)
```

Demo admin: `admin@demo.local` / `demo-admin-password`. Student accounts: use Sign up.

## Tests

```bash
npm test            # 10 end-to-end tests against an in-memory MongoDB
```

## Update the lessons

When the lesson files in `activity-app/www` change, run `npm run build-content` to copy them into `content/`.

## Deploy (Google Cloud Run)

See `deploy/deploy-portal.sh` at the repository root. Environment variables are listed in `.env.example`.

| What | Needed for |
| --- | --- |
| `MONGODB_URI`, `JWT_SECRET` | everything (the deploy script makes the secret for you) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | creating the first admin |
| `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` | real payments. Webhook URL: `https://YOUR-SITE/api/billing/webhook`, event `payment.captured` |
| `SMTP_URL`, `MAIL_FROM` | password-reset emails |
| `BASE_URL` | links in emails, same-site checks |
| `ENROLL_KEY` | the apps use it once to register a screen (the deploy script makes one) |
| `USAGE_DB` | database holding the apps' usage (default `skolar`, the old analytics database, so earlier data carries over) |

### Pointing the apps at this site
In the apps, set the analytics address to `https://YOUR-SITE/api/v1` (same enrollment key as `ENROLL_KEY`). Screens already registered with the old analytics backend keep working if you deploy this site with the same `MONGODB_URI`, `USAGE_DB=skolar` and the same enrollment key as that backend.

Without Razorpay keys the live site shows "payments not switched on" instead of taking fake payments.

## Before you take real money

- Fill in the plan prices in the Admin → Plans page (the defaults are placeholders).
- Replace the draft Privacy, Terms and Refund pages (`public/*.html`, generated by `scripts/make-pages.js`) with text checked by a lawyer, and add your company name and support email.
- GST invoices are not built.
